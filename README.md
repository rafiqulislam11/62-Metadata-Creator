# 62-Metadata-Creator

## RI Creative Agency - AI Microstock Metadata Studio (PRO 2026)

A high-performance, single-file AI Microstock Metadata Generation Studio built for microstock contributors (Adobe Stock, Shutterstock, Freepik, Getty Images, Vecteezy, Envato Elements, 123RF, Dreamstime, Alamy, Canva, and more).

### 🚀 Key Features

- **Google Gemini 2.0 Flash Vision Multimodal Engine**: Analyzes actual visual image pixels for 100% accurate titles, descriptions, categories, and keyword generation.
- **Smart Client-Side Semantic Perception Engine**: Built-in visual classifier recognizing 20+ stock categories and 500+ commercial themes with zero server delay.
- **Microstock Compliance**: Strict enforcement of Adobe Stock (up to 49 single-word keywords, 4 CSV columns), Shutterstock category mapping, and Getty vocabulary.
- **High-Density "Small Style" Cockpit**: Compact, sleek, proportional cards and controls for desktop and laptop displays.
- **Dual Visual Modes**:
  - 🎨 Daylight Aurora Mesh Gradient Theme
  - 🌙 Obsidian Dark Glass Studio Theme
- **Mass Batch Processing**: Capable of processing up to 1,000 files in a high-speed windowed queue filmstrip.
- **Instant Export Formats**: Adobe CSV, Shutterstock CSV, Freepik CSV, Universal Microstock CSV, TXT, and JSON.
- **Zero-Build Architecture**: 100% self-contained in a single `index.html` file.
